# Troubleshooting

| Issue | Solution |
|-------|----------|
| Build fails: multiple errors | Read ALL errors, fix ALL in one pass, rebuild once |
| Git command fails | Use plain `git` in repo CWD; `git -C <path>` only for cross-directory |
| Find past session knowledge | `~/.claude/kb/search-kb.sh --tag <tag>` |
| Can't find memory/conversation | `~/.claude/scripts/search-memories.sh` or `grep -r` in `~/.claude/sessions/` |
| Subagent Bash permission denied | Subagents have sandboxed Bash; set CWD to target dir or have parent handle cross-dir ops |
| `Cannot create agent worktree: not in a git repository` | Task tool needs git repo CWD. From non-git scratch dir, `cd` into real repo before dispatching, or work inline in parent. |
| `git rm` on untracked file | Use `rm` for files never committed; `git rm` only works on tracked files |
| `git add kb/index.tsv` rejected: "paths are ignored" | `kb/index.tsv` is gitignored — auto-generated by `search-kb.sh --rebuild-index`. Stage only `kb/entries/*.md`. |
| Can't find shell command/alias | **Check `~/.localrc` first** for aliases/functions |
| `gh pr edit` missing scopes | Run `gh auth refresh -s read:project` |
| `gh auth status` fails but `GH_TOKEN` is set | `gh auth status` checks keychain, not env var. Probe `gh api /user` or `gh api /rate_limit` directly |
| `(eval): read-only variable: status` | zsh reserves `status` as read-only (`$?` alias). Use different variable name: `result`, `output`, `git_status` |
| `enablePullRequestAutoMerge` / merge method not allowed | Repo may require squash merge only. Use `gh pr merge --squash` |
| `Your branch and 'origin/main' have diverged` after PR squash-merged | After squash merge, local commits orphaned. Reset: `git fetch origin && git reset --hard origin/main`, then `git branch -D <feature-branch>` |
| `gh api ... 2>&1 \| python3 -c "json.load(sys.stdin)"` → `JSONDecodeError` | `2>&1` merges stderr into stdin, breaking JSON parse. Drop `2>&1` when piping to JSON parser, or use `gh api --jq '.field'` |
| Grep/Glob fails: `ENOENT: posix_spawn 'rg'` | `rg` (ripgrep) not on PATH. Fall back to `Bash` with `grep -r` or `find` |
| `'utf-8' codec can't decode byte 0xXX` | Subprocess captured with `text=True` (system locale) instead of `encoding="utf-8", errors="replace"`. Fix: `subprocess.run(..., capture_output=True, encoding="utf-8", errors="replace")` |
| Hook not firing | `chmod +x ~/.claude/hooks/*.sh`; check settings.json hook syntax |
| KB search not found | `~/.claude/kb/search-kb.sh --rebuild-index` |
